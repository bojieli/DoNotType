# Code of conduct

## The short version

Be decent. Argue with the work, not the person.

## What that means here

This project is unusual in one way that shapes how disagreement should go: **claims about
transcription quality are settled by measurement, not by seniority or by confidence.** Three
plausible-sounding changes in this project's history were measured and did the opposite of what was
predicted. So:

- "I think this is better" is an invitation to measure, not an argument to win.
- Being wrong after measuring is a completely normal outcome and carries no cost. The changelog is
  full of it, including entries where the maintainer was wrong.
- Reviewing someone's numbers sceptically is welcome. Dismissing their numbers without running
  anything is not.

## Not acceptable

Harassment, insults, or personal attacks. Sexualised language or imagery. Publishing anyone's
private information. Sustained disruption of a discussion. Deliberately posting someone else's
transcripts or screen contents — this is a project about people's words, and the same care applies
in the issue tracker.

## Scope

Issues, pull requests, discussions, commit messages, and anywhere someone is representing the
project.

## Reporting

Email <bojieli@gmail.com>. Reports are handled privately. If a report concerns the maintainer, say
so and it will not be handled by him alone.

Consequences run from a request to stop, through removing a comment, to a ban. Which one depends on
severity and on whether it happened again.
