DoNotType — Third-Party Notices
================================

DoNotType itself is distributed under the MIT License (see the bundled LICENSE file).
This file credits the open-source software DoNotType ships or builds upon, and reproduces
the licences those components require to be passed on to you.

It is in two parts. Part 1 names every component, its version, and what it is used for.
Part 2 carries the full licence texts. The split exists because most of these components
share three licences between them: repeating the Apache License eleven times would bury the
part that differs — the copyright lines and the attribution notices — under the part that
does not.

Only components that ship inside a released binary are listed. Test-only dependencies
(JUnit, xUnit, Espresso, AndroidX Test) are deliberately absent: they are not in the app you
received, so a licence obligation they carry is not one this file can discharge on your
behalf.


PART 1 — COMPONENTS
===================

Silero VAD
----------
Voice activity detection model by Silero Team.
Version: v6.2.1  ·  Licence: MIT
https://github.com/snakers4/silero-vad
Ships on: macOS, iOS, Windows, Android.

Copyright (c) 2020-present Silero Team

The model file's own notice — which additionally records the commit and the SHA-256 of
the exact weights that shipped — travels next to the model as SILERO-VAD-NOTICE.txt.

ONNX Runtime
------------
Runs the VAD model on every platform.
Version: 1.24.2 (macOS/iOS, onnxruntime-swift-package-manager), 1.29.0 (Windows,
Microsoft.ML.OnnxRuntime; Android, onnxruntime-android)
Licence: MIT
https://github.com/microsoft/onnxruntime
Ships on: macOS, iOS, Windows, Android.

Copyright (c) Microsoft Corporation.

ONNX Runtime statically links a large set of its own upstream dependencies and ships a
6,000-line ThirdPartyNotices.txt covering them. That file is not reproduced here, because
copying it would mean asserting it is current for the exact build that shipped, and only
Microsoft can say that. It is published per release at:
https://github.com/microsoft/onnxruntime/blob/main/ThirdPartyNotices.txt

Version: 1.8.2  ·  Licence: Apache-2.0 with the Swift Runtime Library Exception
https://github.com/apple/swift-argument-parser

Copyright (c) Apple Inc. and the Swift project authors

and 4(d) for the portions embedded into a compiled binary. It is credited here anyway:
the exception says attribution is not owed, not that it is unwelcome. The exception text
follows the Apache License in Part 2.
